# Package index

## All functions

- [`ll_app()`](https://giocomai.github.io/latlon2map/reference/ll_app.md)
  : Run the Shiny Application
- [`ll_bbox()`](https://giocomai.github.io/latlon2map/reference/ll_bbox.md)
  : Provide a bounding box with a consistent, user given ratio
- [`ll_create_folders()`](https://giocomai.github.io/latlon2map/reference/ll_create_folders.md)
  : Create folders to store geographic data
- [`ll_export_sf_to_kml()`](https://giocomai.github.io/latlon2map/reference/ll_export_sf_to_kml.md)
  : Export sf objects into kml file that can be used with Google Earth,
  Google Maps, etc.
- [`ll_find_file()`](https://giocomai.github.io/latlon2map/reference/ll_find_file.md)
  : Find file names. Mostly used internally
- [`ll_find_pop_centre()`](https://giocomai.github.io/latlon2map/reference/ll_find_pop_centre.md)
  : Find the population-weighted centre of a municipality
- [`ll_get_adm_ocha()`](https://giocomai.github.io/latlon2map/reference/ll_get_adm_ocha.md)
  : Get administrative boundary lines from OCHA database
- [`ll_get_electoral_districts_it()`](https://giocomai.github.io/latlon2map/reference/ll_get_electoral_districts_it.md)
  : Get Italian electoral districts (CC-BY Istat)
- [`ll_get_gadm()`](https://giocomai.github.io/latlon2map/reference/ll_get_gadm.md)
  : Get administrative boundaries
- [`ll_get_lau_eu()`](https://giocomai.github.io/latlon2map/reference/ll_get_lau_eu.md)
  : Gets local administrative units from Eurostat's website
- [`ll_get_lau_nuts_concordance()`](https://giocomai.github.io/latlon2map/reference/ll_get_lau_nuts_concordance.md)
  : Gets correspondence tables between local administrative units and
  nuts from Eurostat's website
- [`ll_get_lau_pt()`](https://giocomai.github.io/latlon2map/reference/ll_get_lau_pt.md)
  : Regions and provinces in Italy (high detail, CC-BY Istat)
- [`ll_get_nuts_eu()`](https://giocomai.github.io/latlon2map/reference/ll_get_nuts_eu.md)
  : Gets NUTS as sf object from Eurostat's website
- [`ll_get_nuts_it()`](https://giocomai.github.io/latlon2map/reference/ll_get_nuts_it.md)
  : Regions and provinces in Italy (high detail, CC-BY Istat)
- [`ll_get_nuts_us()`](https://giocomai.github.io/latlon2map/reference/ll_get_nuts_us.md)
  : Get US counties
- [`ll_get_population_grid()`](https://giocomai.github.io/latlon2map/reference/ll_get_population_grid.md)
  : Get EU 1km population grid
- [`ll_get_population_grid_hr()`](https://giocomai.github.io/latlon2map/reference/ll_get_population_grid_hr.md)
  : Get High Resolution Population Density Maps + Demographic Estimates
- [`ll_get_world()`](https://giocomai.github.io/latlon2map/reference/ll_get_world.md)
  : Get countries as an sf object
- [`ll_match()`](https://giocomai.github.io/latlon2map/reference/ll_match.md)
  : Matches a data frame with longitude and latitude to an sf object
- [`ll_osm_countries`](https://giocomai.github.io/latlon2map/reference/ll_osm_countries.md)
  : Countries and geographic entities for which shapefiles are made
  availabile by Geofabrik
- [`ll_osm_download()`](https://giocomai.github.io/latlon2map/reference/ll_osm_download.md)
  : Download OSM data for whole countries from Geofabrik.
- [`ll_osm_download_it()`](https://giocomai.github.io/latlon2map/reference/ll_osm_download_it.md)
  : Download OSM data in geopackage format for regions, provinces, and
  municipalities in Italy.
- [`ll_osm_extract_it()`](https://giocomai.github.io/latlon2map/reference/ll_osm_extract_it.md)
  : Extract OSM data for regions, provinces, and municipalities in
  Italy.
- [`ll_osm_extract_roads()`](https://giocomai.github.io/latlon2map/reference/ll_osm_extract_roads.md)
  : Extract from zip shape files of roads from previously downloaded
- [`ll_osm_get_lau_streets()`](https://giocomai.github.io/latlon2map/reference/ll_osm_get_lau_streets.md)
  : Get all streets available in OpenStreetMap located in given local
  administrative unit.
- [`ll_osm_get_nuts_streets()`](https://giocomai.github.io/latlon2map/reference/ll_osm_get_nuts_streets.md)
  : Get all streets available in OpenStreetMap located in given NUTS.
- [`ll_osm_get_roads()`](https://giocomai.github.io/latlon2map/reference/ll_osm_get_roads.md)
  : Extract shape files of roads from previously downloaded
- [`ll_osm_it_gpkg`](https://giocomai.github.io/latlon2map/reference/ll_osm_it_gpkg.md)
  : Geographic entities in Italy for which geopackage files are
  availabile
- [`ll_set_folder()`](https://giocomai.github.io/latlon2map/reference/ll_set_folder.md)
  : Set folder for caching data
- [`population_grid_hr_metadata`](https://giocomai.github.io/latlon2map/reference/population_grid_hr_metadata.md)
  : A data frame with links to High Resolution Population Density Maps
  distributed by Facebook on HDX
