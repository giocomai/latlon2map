# Geographic entities in Italy for which geopackage files are availabile

A dataset with all names of geographic entities available for direct
download as geopackage files They are used to download files with
[`ll_osm_download_it()`](https://giocomai.github.io/latlon2map/reference/ll_osm_download_it.md)

## Usage

``` r
ll_osm_it_gpkg
```

## Format

A list of tibbles

## Source

<https://osmit-estratti.wmcloud.org/>
